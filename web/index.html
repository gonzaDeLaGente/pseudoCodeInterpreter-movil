PSeInt Móvil

Una versión no oficial de PSeInt para el celular. Ejecuta el intérprete original de PSeInt, compilado a WebAssembly, así que los programas se comportan igual que en la computadora. Funciona sin conexión.

PSeInt fue creado por Pablo Novara y es software libre (GPL). pseint.sourceforge.net

Esta adaptación también es software libre bajo la misma licencia.
